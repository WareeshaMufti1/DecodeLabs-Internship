DecodeLabs Internship Projects

This repository contains the projects completed during my internship at DecodeLabs. Each folder is a standalone front-end project built with HTML, CSS, and JavaScript.

📁 Projects
Project 1 – CircuitCraft

A landing page for CircuitCraft, a fictional IoT/smart devices company. Includes an About section, a Services grid (Hardware Design, Software Development, IoT Integration), and a Contact section with email, phone, and address details.

Tech stack: HTML, CSS

Project 2 – Little Whisk Bakery

A bakery ordering page for Little Whisk Bakery. Customers can browse a cake menu with quantity selectors and an "Add to Cart" button, view a live cart summary with total price, and reach out via a contact form.

Tech stack: HTML, CSS

Project 3 – Legacy Dojo

A student learning dashboard called Legacy Dojo. Includes a sign up / log in flow (accounts stored in the browser's localStorage), and a dashboard that greets the logged-in student, shows a progress bar, and lists their classes.

Tech stack: HTML, CSS, JavaScript
